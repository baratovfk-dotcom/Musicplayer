# 🎵 Music Player

Material 3 музыкальный плеер с фоновым воспроизведением, MediaSession и Audio Focus.

## ✨ Возможности
- 🎨 Material 3 UI
- 🎧 Фоновое воспроизведение (Foreground Service)
- 🔒 MediaSession — управление с экрана блокировки
- 🔊 Audio Focus — авто-пауза при звонках
- 📜 Плейлист из MediaStore

## 📲 Скачать APK
1. Откройте вкладку **Actions**
2. Выберите последний **Build APK**
3. Скачайте артефакт `MusicPlayer-debug`
4. Распакуйте → установите `app-debug.apk`

## 📋 Требования
- Android 7.0+ (API 24)
- Разрешения на аудио и уведомления
